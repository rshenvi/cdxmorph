This page runs the whole program inside your browser. Your file is read on this computer and never uploaded — there is no server behind this page.

or drop one here — ChemDraw → File → Save As → ChemDraw XML

Already have a mapping? Drop its .json in as well, together with the structure or after it, and it is used as saved.

Python starts when you pick a file. The first run downloads the runtime and the scientific libraries (tens of megabytes, once — your browser keeps them after that).
